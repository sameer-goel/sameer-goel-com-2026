Associate · Foundations

Use Claude to get real work done

Who it is for

  • Ops, marketing, product, education, comms
  • No coding and no API experience needed
  • Sits between casual users and engineers

What it covers

  • Output evaluation and validation 21% of the exam, the heaviest domain
  • Prompting, product and model selection
  • Projects, Artifacts, connectors such as Drive and Gmail
  • Governance and responsible use
Developer · Foundations

Build, integrate and ship with Claude

Who it is for

  • AI, ML and software engineers, tech leads
  • One to five years experience, Python or TypeScript
  • Comfortable with REST APIs and the CLI

What it covers

  • Applications and integration 33% of the exam, it dominates
  • Agents and workflows, plus Claude Code
  • Model selection, prompt and context engineering
  • Security and safety, tools and MCP
Architect · Foundations

Design production systems that hold up

Who it is for

  • Solution architects designing real deployments
  • Six months hands on with the SDK, Claude Code and MCP
  • Scenario basedfour scenarios drawn from a bank of six

What it covers

  • Agentic architecture and orchestration 27% of the exam, the heaviest domain
  • Tool design and MCP integration
  • Claude Code configuration and workflows
  • Structured output, context and reliability
Architect · Professional

Own the lifecycle and answer to the business

Who it is for

  • Mid to senior architects and technical leads
  • Three years of architecture, bridging business and technical
  • Advises clients, legal and executives

What it adds on top

  • Integration 19% of the exam, the heaviest domain
  • Governance: GDPR HIPAA FedRAMP
  • Stakeholder communication, SLAs, lifecycle
  • Ethical AI: bias, fairness, transparency

The payoff: what you keep for life

Six instincts these certifications install

1
Trust but verify
Never forward a confident answer without checking the source.
2
Match tool to job
Stop reaching for Opus. Could Haiku do it cheaper and faster?
3
Least privilege
Do not hand an agent "delete" when it only needs "read".
4
Enforce, do not ask
When it must happen, use code and hooks, not a polite prompt.
5
Know when to escalate
Recognise the edge of your competence and hand off cleanly.
6
Design for failure
Structured errors, partial results, graceful degradation.
If you are a forward deployed or enterprise engineer
These certifications install the decision making instincts you would otherwise learn from three years of painful production incidents.
Rapid fire · choosing a path

"Which one should I start with?"

"I am not a coder. Which certification?"
Associate. No API and no development experience required.
"Engineer with six months of Claude. Developer or Architect?"
Developer if you build and ship code. Architect Foundations if you design systems and make the tradeoff calls.
"Do I need Foundations before Professional?"
No. Associate, Developer and Professional each state no prerequisites outright. Architect Foundations publishes recommended experience instead. The credential is awarded on exam performance.
"Foundations versus Professional Architect?"
Foundations is scenario based and hands on. Professional adds governance, stakeholders, compliance and lifecycle.
Rapid fire · content and myth busting

"What is guaranteed to be on it?"

"The heaviest topic on each exam?"
Associate: output validation 21%. Developer: applications and integration 33%. Architect Foundations: agentic orchestration 27%. Architect Professional: integration 19%.
"Bigger model means a better answer?"
No. Match the model to the task: cost, latency, quality.
"Can I just tell the model to be careful to make it safe?"
No. Polite instructions are not enforceable. Use hooks and least privilege.
"Is self reported confidence a good accuracy signal?"
Usually not. Associate and Architect Foundations both call it unreliable, and Developer teaches scepticism toward confident output. One exception: Architect Foundations does use self reported confidence to route findings for calibrated review.
How it is actually done

Do not just read. Build one thing.

Associate

  • Configure a Project with instructions and knowledge sources
  • Practise evaluating outputs for accuracy and bias

Developer

  • Build an agent: tool calling, error handling, sessions
  • Add a custom tool or an MCP server

Architect · F

  • Design a multi agent system with retrieval
  • Add evaluation and observability

Architect · Pro

  • Take one system end to end
  • Add governance, SLAs and stakeholder documents
Good to know

Logistics that apply to all four

  • Multiple choice and multiple response each item tells you exactly how many options to pick
  • Retakes allowed waits of 14, 30 and 90 days, up to four attempts per rolling 12 months
  • Expires after 12 months free non proctored renewal if you renew on time
  • No prerequisites on three of the four Architect Foundations publishes recommended experience instead, but the credential is still earned on exam performance
